How this works

      
The item's owner published one P-256 public key per 15-minute epoch. This is epoch  and its key is

      

      
Your browser makes a throwaway key pair, does ECDH with that key, derives an AES-256-GCM key with HKDF, and encrypts your location. The server indexes the result by SHA-256 of the public key and stores the bytes for 7 days.
